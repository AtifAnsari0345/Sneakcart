# SneakCart

SneakCart is an e-commerce Progressive Web App designed specifically for sneaker shopping. It provides a clean UI, product filters, and a PWA shopping experience.

---

## 🚀 Features
- Sneaker product listing & filtering
- Search functionality
- Add-to-cart and checkout UI
- Fully responsive design
- Lightweight PWA with offline access

---

## 🛠️ Tech Stack
HTML • CSS • JavaScript (Vanilla)
